# The Verification Layer

**Nobody verifies what agents claim.** Across eleven territories of the AI stack — agent side effects, explanations, inter-agent claims, agent-run companies, prediction-market leaderboards, quantized model files, tournament selection, agent memory, code intelligence graphs, ontology-grounded reasoning, and embedding indexes — systems assert, and nothing checks.

This site is the full programme document for the eleven open-source verification tools built to close that gap: the landscape scans, the selection reasoning, the designs and architecture, step-by-step walkthroughs with real code, the measured results, and the honest limitations.

**Read it: https://ranadhir19.github.io/verification-layer/**

The tools (all under [github.com/ranadhir19](https://github.com/ranadhir19)):

- **effectreckon** — verifies the effects an agent's actions actually had
- **foriscope** — verified black-box explanations
- **deedreckon** — checks claimed work against evidence
- **podiumproof** — audits tournament and judge verdicts
- **claimwitness** — signed, verifiable claim envelopes between agents
- **memreckon** — verifies agent memory entries instead of trusting them
- **zombieaudit** — recomputes prediction-market leaderboards fee-net, zombie-adjusted
- **quantseal** — measures the real quality cost of a quantized model file
- **edgereckon** — verifies code-graph edges against execution traces
- **ontoreckon** — stamps ontology conformance and path validity
- **embedreckon** — audits embedding spaces and certifies migrations before cutover

A companion video series walks through each tool on the YouTube channel *The Architect's AI Workshop*.
